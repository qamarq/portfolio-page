- Next.js and Auth.js
- React Three Fiber for the 3D configurator

- MongoDB

## Key features

- 3D configurator with many options
- Custom CMS and admin dashboard
- Accounts with roles and a guest cart
- Full payment flow with webhooks
- Blog module
